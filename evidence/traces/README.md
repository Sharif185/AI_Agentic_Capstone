# Evidence — Agent Traces

This directory contains JSON execution traces from the bounded StudentSupportAgent (Week 5).
Traces are generated by **Mus's `Tracer`** (auto-named `TRACE-YYYYMMDDHHMMSS-xxxxxx.json`)
and copied to fixed names by **Louis's test harness** (`tests/test_agent.py` via `shutil.copy2`).

## Trace Index

| File | Scenario | Goal | Stop Reason | Iterations |
|---|---|---|---|---|
| `TRACE-001.json` | Happy path | "I want to register for BSE4104. What do I need?" | `stop_requested` | 2 |
| `TRACE-002.json` | Approval gate | "What are the prerequisites for XYZ999?" | `stop_requested` | 2 |
| `TRACE-003.json` | Bounded failure | "I have a problem." | `stop_requested` | 1 |
| `run-summary.json` | All scenarios | — | Summary of all 3 runs | — |

Auto-named originals (e.g. `TRACE-20261002065103-fc5d13.json`) are also present in this
directory. The fixed-name files are `shutil.copy2` copies for consistent cross-team referencing.

## Trace Schema

Each `TRACE-NNN.json` file contains:

```
{
  "trace_id":        string   — unique trace identifier (auto-generated by Mus's Tracer)
  "goal":            string   — student's original question
  "started_at":      string   — ISO timestamp
  "iterations":      array    — per-iteration records (plan, action_taken, timestamp)
  "tool_calls":      array    — every tool execution with arguments and result
  "rag_calls":       array    — every RAG query with num_results and sources
  "human_approvals": array    — every approval decision (tool, arguments, approved)
  "final_response":  string   — agent's final reply to the student
  "stop_reason":     string   — why the loop ended
  "completed_at":    string   — ISO timestamp
}
```

## Notes on Stop Reason

All three traces show `stop_requested`. In scenarios 1 and 2 this was caused by a Gemini 503
rate-limit on the second planning call — the Planner's exception handler caught it and converted
it to a safe `stop` decision. In scenario 3 the planner chose `stop` immediately because the
goal ("I have a problem.") was too vague to act on. No scenario crashed or exceeded a limit.

## How to Re-Run

```bash
python tests/test_agent.py
```

(Run from the project root.)

The fixed-name trace files are overwritten on each run. Auto-named originals accumulate.
Archive previous fixed-name traces before re-running if comparison is needed.
